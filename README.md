# Weather-App 🌤️

A simple **Weather Forecast Web Application** built with **React** and **Material-UI**.  
Get real-time weather updates for any city with a clean and responsive user interface.

---

## 🚀 Features

- Search weather by city name 🌆
- Displays temperature, humidity, wind speed, and weather description 🌡️💨
- Responsive and mobile-friendly design 📱
- Built with React and Material-UI for a modern UI ✨
- Uses free weather API for fetching live data 🌐

---

## 🛠️ Technologies Used

- **Frontend:** React.js, Material-UI  
- **API:** OpenWeatherMap API (or any other weather API)  
- **Styling:** CSS, Material-UI components  
- **Bundler:** Vite
